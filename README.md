# CodSoft Java Programming Internship Projects

This repository contains the projects I developed during my Java Programming Internship at CodSoft.
These projects helped me strengthen my understanding of Core Java, Object-Oriented Programming (OOP), collections, exception handling, loops, conditional statements, and user interaction through console-based applications.

Projects Included
# 1. Student Grade Calculator

A Java-based application that calculates total marks, average percentage, and grade based on marks entered by the user. The system validates input marks and generates the final result automatically.

<ins>Features</ins>
+ Accepts student details and subject marks
+ Calculates total marks and average percentage
+ Grade evaluation system
+ Input validation for marks
+ Console-based user interaction
  
<ins>Concepts Used</ins>
+ Loops
+ Conditional Statements
+ User Input Handling
+ Arithmetic Operations
+ Java Scanner Class
  
# 2. ATM Interface

A console-based ATM simulation system developed using Java. The application allows users to check balance, deposit money, withdraw money, and interact with banking operations through a menu-driven interface.

<ins>Features</ins>
+ Balance checking
+ Deposit functionality
+ Withdraw functionality
+ Insufficient balance handling
+ Menu-driven ATM interface
  
<ins>Concepts Used</ins>
+ Object-Oriented Programming (OOP)
+ Classes and Objects
+ Encapsulation
+ Methods
+ Conditional Logic
  
# 3. Quiz Application with Timer

A Java quiz application that includes multiple-choice questions and a timer mechanism for answering each question within a limited time. The application evaluates answers and displays the final score at the end.

<ins>Features</ins>
+ Multiple-choice quiz system
+ Timer for each question
+ Automatic score calculation
+ Exception handling for timeout
+ Result display at the end of the quiz
  
<ins>Concepts Used</ins>
+ Multithreading
+ Exception Handling
+ Arrays
+ Classes and Objects
+ Time Management using Threads
  
# 4. Student Course Registration System

A Java-based course registration system where students can register for courses, remove registered courses, and view available course listings. The system also manages course capacity dynamically.

<ins>Features</ins>
+ Course listing system
+ Student registration
+ Course removal
+ Dynamic seat availability management
+ Student-course relationship management
  
<ins>Concepts Used</ins>
+ Java Collections Framework
+ ArrayList
+ HashMap
+ Object-Oriented Programming
+ Data Management
